Relaciones con otros componentes

  • MainWindow se registra a sí misma como servicio del Kernel ("MainWindow") en su constructor, y escucha kernel.event mediante on_kernel_event.
  • MainWindow consulta el servicio DataStore (vía kernel.get_service("DataStore")) para poblar la lista de señales y decidir la visibilidad de la marca de agua.
  • MainWindow invoca get_widget(), start(), process() y stop() de cada IPlugin registrado (ver componente ApplicationCore/Plugins).
